- 目前自動研究只跑F基準與兩個單條件版本，每次最多3個實驗／600秒。舊A／B／C不再參賽；85%不是必要晉級條件，成本、期望值、樣本數、回撤與穩健性門檻繼續保留。
- 每次命令執行都有獨立run_id、程式／資料指紋、修改原因、勝率、已平倉筆數、平均驗證淨報酬、最大單折回撤、PF、期望值、費用與保留狀態；資料不足、錯誤、虧損與未保留都會記錄。
- 網站新增「每次回測結果」，可展開並下載完整報告；Actions摘要同步顯示。每次研究完成即發布研究頁，不等下次每日更新，也不會啟用未驗證候選。
- `runs/ledger.jsonl`與每次完整JSON持久保存在research-data分支；網站索引最近200次、顯示與提供最近20次完整報告，其餘仍可查資料分支，非挑選有利結果。正式凍結檔與研究提案繼續分離。

本次又從官方增量回補29個日期，59次HTTP嘗試、182.35秒後依資源預算停止，補至2021-09-17；研究截止2026-10-16的資料共735,024筆、390個零散有行情日期。仍缺978個工作日日報／休市證據；613,582筆缺官方成交金額、614,873筆缺當日參考價。完整官方公司行動母表仍未接妥，不能把首尾跨度稱為五年完整資料。

## 驗證與操作

新增測試涵蓋：僅允許F參加目前研究、RSI所有執行入口拒絕、兩種初始事件共用回測進場、事件量與進場量不可省略、回檔擴量不買、結構未改善不買、未來K棒不能改訊號、次日開盤與成本、每次失敗／資料不足均入帳、虧損不被移除、匯出歷史不製造新執行、CLI錯誤也產出報告。合成數字僅用測試，不放到公開績效或Actions的正式回測摘要。

```bash
python3 -m screener.optimizer research  # 每次都留紀錄，資料不合格則停止
python3 -m screener.reporting export    # 只恢復網站紀錄，不執行新回測
python3 -m unittest discover -s tests -v
RUN_LIVE_TESTS=1 LIVE_DATE=2026-10-16 python3 -m unittest discover -s tests -v
```

台北01:00限額回補與單策略研究、平日18:30官方更新／每日報告，手動也可執行research.yml。來源失敗仍保存完成日期與錯誤，研究錯誤仍保存／發布報告後標記失敗。GitHub排程可能延遲或被停用，需以實際Actions紀錄為準，未來自然觸發不冒稱已驗證。

聊天視窗無背景主動推播功能；本次可在聊天回報，後續每次自動結果會出現在網站與Actions摘要。正式策略及前瞻紙上帳本目前均停用，無可信的新策略勝率可報。操作、備份與資料來源詳見[README](../README.md)、[資料缺口](data-sources.md)。
