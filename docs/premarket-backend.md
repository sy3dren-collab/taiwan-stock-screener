# 台指期當沖情報站：GitHub 更新方式

依使用者要求跳過 Cloudflare，不再需要外部部署帳號、Worker網址或API設定。舊部署程式已移除；既有 `MARKET_BRIEF_API` 變數即使仍存在，也不會啟用外部服務。

## 更新方式

- GitHub Actions 每週一至週五台北08:10自動執行，可能因排隊延遲；收集與產生時間都會顯示。
- 「重新讀取最新發布資料」只重新下載Pages上的JSON，不宣稱觸發原始來源收集。
- 「前往GitHub啟動新收集」使用既有GitHub帳號，登入後按Run workflow；不新增平台帳號。本頁每15秒等候新發布結果，最長20分鐘，逾時顯示工作可能尚未啟動或失敗。這不是一按即時服務。
- 收集與網站部署通常需數分鐘。GitHub原有額度仍依儲存庫方案計算，本次未開通付費方案或訂閱。

## 來源與資料語義

共用的公開來源收集器為 `market/collector.mjs`，來源清單在 `market_sources.json`；GitHub執行 `node scripts/publish_premarket.mjs`。只收集免登入、免金鑰的公開回應，401／402／403／429分別標記需驗證、需付款、拒絕存取或限流，跳過該來源。不登入、不開通訂閱、不繞過限制，也不拿其他行情冒充。

Yahoo公開行情保留來源最新報價時間與前次收盤基準，可能延遲；VIX、利率與匯率的上升不代表台指期上漲。期交所DailyMarketReportFut是交易報表，不是即時價；保留TX合約月份、交易日及原始日／夜盤欄位。不能用現貨指數替代期貨，也不猜換月與到期交易指令。

新聞只顯示公開RSS標題、來源、發布時間與原文連結，以半導體／權值股、央行／數據、地緣／政策、股匯市等關鍵字作相關性標記，不推論做多做空。RSS不是完整新聞庫；原文網站若要求訂閱，不表示本站取得其付費全文。沒有可靠資料時不編造標題、事件日期或行情。

## 驗證與連線限制

`node tests/market-collector.cjs`、`node tests/premarket-browser.cjs`、`python -m unittest discover -s tests`。瀏覽器測試資料只存在請求攔截中，不能寫入發布報告。

本地新增來源網域設定已存草稿，未套用前連線代理仍可能回403。這不能直接證明提供者要求註冊；需在允許的執行環境驗證。GitHub收集失敗也會發布明示錯誤的報告，不能將錯誤狀態宣稱更新成功。
