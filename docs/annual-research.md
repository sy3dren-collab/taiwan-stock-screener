# 單一合併策略的一年回溯診斷

本入口回應「先回測一年、排除反覆停止的問題」。它使用原有合併策略 F 與原有真實價格交易引擎，不取消五年研究、公司生命週期完整性或一次性封存測試的晉級檢查。

## 固定資料與規則

- 評估期：2025-10-17～2026-10-16。暖機從2025-04-01開始；不將首尾跨度冒稱完整交易日。
- 本期已被先前研究使用，固定標記 `retrospective_diagnostic`；`promotion_allowed: false`。不更改 `docs/data-exposure.json`、正式策略登錄或封存測試狀態。
- 只跑 F：「長整理大量收復／突破 → 高低點抬高 → 量縮回測支撐 → 放量轉強」。參數沿用 `naked_k.json`，未因缺資料降低流動性、價位、風險或量能門檻。
- 本金100萬、最多5部位、1000股整張、單筆初始風險最多1%，雙邊手續費0.1425%、賣出稅0.3%、單邊滑價0.1%，與原引擎一致。
- 收盤訊號隔日有效開盤成交。第20個交易日開盤到期，停損／目標可更早；同根同碰停損與目標先停損。期末前20個交易日停止接受新訊號，避免以未完成交易美化勝率。

## 資料准入

全期間每個工作日必須有兩市場日報或官方休市回應、來源雜湊及抓取時間，原子提交兩市場。每個完整OHLCV資料列須有官方實際成交金額。來源錯誤不視為休市；未回補完成不能縮短期間冒稱全年。資料庫完整性與日期筆數一致性仍是全體門檻。

資料指紋v2依實際輸入行情、選用歷史事件欄位與公司行動紀錄計算；抓取時間、來源與原始回應雜湊另存`evidence_sha256`。重抓相同行情只改變證據指紋，不會誤判為不同的財務輸入。更改價格、成交金額、事件比率、股利或日期仍會改變資料指紋；完整官方來源門檻保持不變。原始表中的今日財報欄不參與訊號或財務資料指紋。

TWSE `TWT49U` 與 TPEx `exDailyQ` 官方除權息表完整查詢，保留原始JSON與來源雜湊。只介接能明確認定的純現金除息，**權值＋息值只在純「息」類型才當作現金值**；配股／現增事件不猜股數。財報及最近申報欄完全不用於歷史訊號。

訊號歷史用理論除息價比率調整；交易價格保持原始價格。漲跌幅與連續性使用同日官方「開盤競價基準／開始交易基準價」，與理論參考價可能因跳動單位不同，不能強迫相等。X／除息日缺失的日報參考價只從該官方基準補入，並保留原始日報與事件來源證據。

公告時間保守採事件生效日，不提前使用。股息計入已知應收款；官方表沒付款日便不假設能再投資。尚不能宣稱完整處理股票分割、減資、下市、身份轉換或個人所得稅，也不填入 `lifecycle_coverage` 假裝全集已齊。

個股須有100根連續有效市場交易日K線及前根基準核對資料。當時已知的未支援事件、無OHLC、無成交或參考價無法核對會中斷暖機；後續重新累積足夠歷史才恢復訊號。排除以當時資訊逐日判斷，不先偷看未來事件整檔移除。未知事件若發生在已持有股票上，整輪模擬失敗；不刪除虧損交易、不按最後收盤強制結算。

股票池來自各日的歷史日報，不使用今天的上市名單；四位數代碼規則仍欠完整歷史證券類別／生命週期母表，因此結果只具有限定資料政策下的研究意義。

## 可追溯報告及自動化

`annual-backtest.json` 保存整年連續帳戶淨值、交易、費稅滑價、逐月報酬、持倉／應收款、進場拒絕原因與逐日資料准入統計。它的「一年帳戶淨報酬」與原五年流程的「跨折平均驗證報酬」是不同數值，前端及帳本分欄保存。

每次執行成功、資料不足或錯誤都新增不可變run快照與帳本；所有交易均保留。沒有交易時勝率為null／—，不是0%勝率，也不能將0%帳戶報酬當作有效策略。年度檔案隨資料庫備份到research-data，日常發布會一併還原，不會被五年阻擋報告取代。

每輪最多220日期、500HTTP嘗試（含重試）、1200秒。最多三日期並行，同一官方主機請求間隔至少1秒。中斷時已提交日期保留，下輪掃描缺失日期續接。每輪回測上限900秒，不能產生部分績效冒充完整回測。夜間01:00台北優先續接一年資料並執行研究；實際結果在網站與Actions摘要可見，沒有聊天背景推播。


## 固定基準與單條件研究

完整一年基準已完成，242交易日、131,078個資料准入股票日，進場訊號及交易均為0；勝率null、帳戶報酬0%，不能解釋為策略有效。逐層拒絕統計見 [紀錄](rejection-counts-2026-10-19.json)；這是回傳None原因的插樁計數，不是另一輪交易回測。原函式行號與程式版本均保留，可用 `PYTHONPATH=. python3 scripts/analyse_fusion_rejections.py` 重現（需要完整資料庫，輸出在/tmp）。插樁先用既有純測試fixture確認函式輸出不變；測試資料不存入行情或報告。

預先登記只做一個對照：`--variant wider-range` 將 `range_width` 由0.25改為0.30，漂移8%、量能、結構、停損、1.5R、成本及資金規則全部不變。假設是25%整理幅度限制使可研究的型態太少，而非為達85%修改門檻。這是同一已知年份的研究，結果無論好壞全部保留，不更改 `naked_k.json` 基準，也不凍結或啟用。

```bash
python3 -m screener.annual research --variant wider-range
```

結果另存 `annual-wider-range.json`，與基準分開；網站只有在資料指紋、成本、風控、進場截止日相同且確實只改區間寬度時才顯示比較。改良結果不自動取代固定基準，夜間預設仍跑基準；Actions手動可指定variant。

2026-10-19實測：30%版本同樣0訊號、0交易、勝率null、淨報酬0%、回撤0%。資料指紋、136日暖機、242日評估、成本、風險與進場截止日與基準一致，只改`range_width`。這個假設未改善訊號數量，不判定勝出。
